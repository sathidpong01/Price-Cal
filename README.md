# 📋 เอกสารประกอบโปรเจค (Project Documentation) - โปรแกรมคำนวณราคา

## 🚀 ภาพรวมโปรเจค (Project Overview)

โปรเจคนี้คือเว็บแอปพลิเคชันสำหรับคำนวณราคาประมาณการของสินค้าประเภทต่างๆ ที่ผลิตตามสั่ง เช่น สติ๊กเกอร์, ป้ายไวนิล, ตัวอักษรโลหะ และกล่องไฟ แอปพลิเคชันถูกออกแบบมาให้ใช้งานง่าย แบ่งออกเป็น 2 ส่วนหลัก:

1.  **👤 หน้าสำหรับผู้ใช้ทั่วไป (`index.php`)**: ใช้สำหรับกรอกข้อมูลจำเพาะของงาน (เช่น ขนาด, จำนวน, วัสดุ) เพื่อคำนวณราคาโดยประมาณ.
2.  **⚙️ หน้าสำหรับผู้ดูแลระบบ (`admin.php`)**: ใช้สำหรับจัดการข้อมูลหลักทั้งหมดที่ใช้ในการคำนวณ เช่น วัสดุ, ราคา, ออปชันเสริม และสต็อกสินค้า.

แอปพลิเคชันทำงานแบบไดนามิก โดยใช้เทคโนโลยี AJAX ในการรับส่งข้อมูลระหว่างหน้าเว็บและเซิร์ฟเวอร์ ทำให้การคำนวณและการจัดการข้อมูลเกิดขึ้นอย่างรวดเร็วโดยไม่ต้องโหลดหน้าเว็บใหม่ทั้งหมด.

## ✨ คุณสมบัติเด่น (Key Features)

* **💰 การคำนวณราคา 4 ประเภท**:
    * สติ๊กเกอร์ (ตามขนาดและวัสดุ)
    * ผ้าไวนิล (ตามขนาดและวัสดุ)
    * ตัวอักษร (ตามความสูง, จำนวน, และวัสดุ)
    * กล่องไฟ (ตามขนาดและประเภท)
* **🛠️ การจัดการข้อมูลเบื้องหลัง**:
    * **จัดการกฎราคา**: เพิ่ม/ลบ/แก้ไข ค่าติดตั้งและค่าเดินทาง.
    * **จัดการวัสดุ**: เพิ่ม/ลบ/แก้ไข วัสดุและราคาต่อหน่วยสำหรับสินค้าแต่ละประเภท.
    * **จัดการออปชันเสริม**: เพิ่ม/ลบ/แก้ไข ออปชันเสริมและราคาสำหรับสินค้าแต่ละหมวดหมู่.
    * **จัดการสต็อก**: เพิ่ม/ลบ/แก้ไข และติดตามจำนวนสินค้าในสต็อก.
* **⚡ ระบบโต้ตอบทันที (Real-time Interaction)**:
    * การคำนวณราคาอัตโนมัติเมื่อผู้ใช้กรอกข้อมูล.
    * การแก้ไขและลบข้อมูลในหน้าแอดมินเกิดขึ้นทันทีผ่าน AJAX.
    * ระบบค้นหาและกรองข้อมูลในตารางสำหรับแอดมิน.
* **🎨 การแสดงผลที่ยืดหยุ่น**: แอดมินสามารถเลือกเปิด/ปิดการแสดงผลของวัสดุ, กฎราคา, และออปชันในหน้าคำนวณได้.
* **🖌️ การออกแบบที่สะอาดตา**: ใช้ธีม "MUJI Minimalist" ที่เรียบง่าย สบายตา และใช้งานง่าย.

## 🖥️ สภาพแวดล้อมที่ต้องการ (System Requirements)

โปรเจคนี้ถูกออกแบบมาเพื่อทำงานบน **Synology NAS** โดยต้องมีการติดตั้งและเปิดใช้งาน Packages ต่อไปนี้:

* **Web Station**: สำหรับรันเว็บเซิร์ฟเวอร์ (Apache/Nginx).
* **MariaDB 10**: สำหรับระบบจัดการฐานข้อมูล.
* **phpMyAdmin**: สำหรับจัดการฐานข้อมูลผ่านเว็บอินเตอร์เฟส.
* **PHP**: แนะนำเวอร์ชัน 7.4 ขึ้นไป.

## 🛠️ การติดตั้งบน Synology NAS (Installation on Synology NAS)

ทำตามขั้นตอนต่อไปนี้เพื่อติดตั้งโปรเจคบน NAS ของคุณ

### ขั้นตอนที่ 1: 📦 ติดตั้ง Packages ที่จำเป็น
1.  เปิด **Package Center** บน DSM ของ Synology.
2.  ค้นหาและติดตั้ง **Web Station**, **MariaDB 10**, และ **phpMyAdmin**.
3.  ติดตั้ง **PHP** (เช่น PHP 8.0) จากใน Package Center.
4.  ไปที่ **Web Station** > **Web Service Portal** และตรวจสอบว่า Default Server ทำงานปกติ.
5.  ไปที่ **Web Station** > **Script Language Settings** และตั้งค่า Default PHP Profile เป็นเวอร์ชันที่คุณติดตั้ง (เช่น PHP 8.0).

### ขั้นตอนที่ 2: 🗃️ ตั้งค่าฐานข้อมูล (Database Setup)
1.  เปิด **MariaDB 10** และตั้งรหัสผ่านสำหรับผู้ใช้ root (หากยังไม่ได้ตั้ง).
2.  เปิด **phpMyAdmin**.
3.  ล็อกอินด้วยชื่อผู้ใช้ `root` และรหัสผ่านที่คุณตั้งไว้.
4.  สร้างฐานข้อมูลใหม่โดยคลิกที่แท็บ **Databases** > ตั้งชื่อเป็น `price_calculator` > เลือก Collation เป็น `utf8mb4_general_ci` > กด **Create**.
5.  เลือกฐานข้อมูล `price_calculator` ที่เพิ่งสร้าง.
6.  ไปที่แท็บ **Import** > กด **Choose File** และเลือกไฟล์ **`mockup-db.sql`** จากโปรเจคของคุณ.
7.  กด **Go** ที่ด้านล่างเพื่อเริ่มการ Import ข้อมูล. เมื่อเสร็จสิ้น คุณจะมีตารางทั้งหมดพร้อมข้อมูลเริ่มต้น.

### ขั้นตอนที่ 3: 📤 อัปโหลดไฟล์โปรเจค (Upload Project Files)
1.  เปิด **File Station**.
2.  ไปที่โฟลเดอร์ `web` ซึ่งเป็นโฟลเดอร์หลักของ Web Station.
3.  สร้างโฟลเดอร์ใหม่สำหรับโปรเจคของคุณ เช่น `price-cal`.
4.  อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดของโปรเจคนี้เข้าไปในโฟลเดอร์ `web/price-cal`.

### ขั้นตอนที่ 4: 🔌 แก้ไขไฟล์เชื่อมต่อฐานข้อมูล (Configure Database Connection)
1.  ใน **File Station**, ไปที่ `web/price-cal/includes/`.
2.  คลิกขวาที่ไฟล์ **`db_connect.php`** แล้วเลือก **Edit in Text Editor**.
3.  แก้ไขค่าตัวแปรให้ตรงกับการตั้งค่า MariaDB 10 ของคุณ:
    * `$db_host`: โดยทั่วไปคือ `localhost` หรือ `127.0.0.1`.
    * `$db_user`: "root".
    * `$db_pass`: "รหัสผ่านที่คุณตั้งไว้ในขั้นตอนที่ 2.1".
    * `$db_name`: "price_calculator".
4.  บันทึกไฟล์.

### ขั้นตอนที่ 5: 🌐 เข้าใช้งาน (Accessing the Application)
* **หน้าคำนวณราคา**: `http://<IP_ของ_NAS>/price-cal/`
* **หน้าจัดการ**: `http://<IP_ของ_NAS>/price-cal/admin.php`

## 📂 โครงสร้างไฟล์ (Project Structure)

โครงสร้างของโปรเจคถูกจัดระเบียบอย่างเป็นระบบเพื่อให้ง่ายต่อการแก้ไขและบำรุงรักษา:

* `📄 **admin.php**`: หน้าหลักสำหรับผู้ดูแลระบบ ใช้จัดการข้อมูลทั้งหมด
* `📄 **admin_ajax_data_handler.php**`: เซิร์ฟเวอร์หลังบ้านสำหรับหน้า Admin จัดการคำขอ (Request) แบบ AJAX เพื่อ เพิ่ม, ลบ, แก้ไข ข้อมูล
* `📄 **calculate_ajax.php**`: เซิร์ฟเวอร์หลังบ้านสำหรับหน้า Index จัดการคำขอ AJAX เพื่อคำนวณราคา
* `📄 **index.php**`: หน้าหลักสำหรับผู้ใช้ทั่วไป, แสดงเครื่องคำนวณและสต็อกสินค้า
* `📄 **mockup-db.sql**`: ไฟล์ SQL สำหรับสร้างตารางและข้อมูลเริ่มต้นทั้งหมดในฐานข้อมูล

* `📁 **css/**`: โฟลเดอร์สำหรับเก็บไฟล์สไตล์ชีท (CSS) ทั้งหมด
    * `📄 admin.css`: สไตล์สำหรับหน้าผู้ดูแลระบบ (`admin.php`)
    * `📄 index.css`: สไตล์สำหรับหน้าผู้ใช้ทั่วไป (`index.php`)
    * `📄 modals.css`: สไตล์สำหรับกล่อง Modal ที่ใช้ในการแก้ไขข้อมูล

* `📁 **includes/**`: โฟลเดอร์สำหรับเก็บไฟล์ PHP ที่เรียกใช้ซ้ำๆ
    * `📄 data_fetcher.php`: รวมฟังก์ชันสำหรับดึงข้อมูลที่ใช้ร่วมกันจากฐานข้อมูล
    * `📄 db_connect.php`: ไฟล์สำหรับเชื่อมต่อฐานข้อมูล MariaDB
    * `📄 modals.php`: โค้ด HTML ของกล่อง Modal สำหรับหน้าแก้ไขข้อมูล

* `📁 **js/**`: โฟลเดอร์สำหรับเก็บไฟล์ JavaScript
    * `📄 admin.js`: โค้ด JavaScript สำหรับหน้าผู้ดูแลระบบ (จัดการ Modal, AJAX, ตาราง, การค้นหา)
    * `📄 index.js`: โค้ด JavaScript สำหรับหน้าผู้ใช้ทั่วไป (ส่งข้อมูลคำนวณ, แสดงผลลัพธ์)

## ⚙️ หลักการทำงาน (How It Works)

### หน้าคำนวณราคาสำหรับผู้ใช้ (`index.php`)
1.  **การดึงข้อมูล**: เมื่อเปิดหน้า `index.php`, สคริปต์ PHP จะดึงข้อมูลเริ่มต้น (วัสดุ, ออปชันที่เปิดใช้งาน) จากฐานข้อมูลผ่าน `data_fetcher.php` เพื่อสร้างฟอร์มต่างๆ.
2.  **การโต้ตอบของผู้ใช้**: ผู้ใช้กรอกข้อมูลลงในฟอร์ม.
3.  **การส่งข้อมูล**: `js/index.js` จะตรวจจับการเปลี่ยนแปลงในฟอร์ม และใช้ `debounce` เพื่อหน่วงเวลาการส่งข้อมูลเล็กน้อย (เพื่อประสิทธิภาพ) แล้วจึงรวบรวมข้อมูลจากฟอร์มนั้นๆ.
4.  **การคำนวณ**: ข้อมูลจะถูกส่งไปยัง `calculate_ajax.php` ผ่าน AJAX.
5.  **การประมวลผล**: `calculate_ajax.php` รับข้อมูล, ดึงกฎราคาและข้อมูลที่จำเป็นจากฐานข้อมูล, ทำการคำนวณ, และส่งผลลัพธ์กลับมาในรูปแบบ JSON.
6.  **การแสดงผล**: `js/index.js` รับข้อมูล JSON กลับมาและแสดงผลลัพธ์ในหน้าเว็บโดยไม่ต้องโหลดใหม่.

### หน้าจัดการสำหรับแอดมิน (`admin.php`)
1.  **การแสดงข้อมูล**: `admin.php` ดึงข้อมูลทั้งหมดจากตารางต่างๆ ในฐานข้อมูล (เช่น price_rules, materials, options, stock) มาแสดงในรูปแบบตาราง.
2.  **การแก้ไข (Edit)**: เมื่อแอดมินกดปุ่มแก้ไข, `js/admin.js` จะส่ง AJAX GET request ไปยัง `admin_ajax_data_handler.php` เพื่อขอข้อมูลของรายการนั้นๆ. จากนั้นข้อมูลจะถูกนำมาแสดงใน Modal แก้ไข.
3.  **การบันทึก (Update)**: เมื่อแอดมินบันทึกการแก้ไขใน Modal, `js/admin.js` จะส่ง AJAX POST request พร้อมข้อมูลใหม่ไปยัง `admin_ajax_data_handler.php` เพื่ออัปเดตฐานข้อมูล.
4.  **การลบ (Delete)**: `js/admin.js` จะส่ง AJAX POST request ไปยัง `admin_ajax_data_handler.php` เพื่อลบรายการออกจากฐานข้อมูล.
5.  **การเพิ่ม (Add)**: การเพิ่มข้อมูลใหม่จะใช้ฟอร์มมาตรฐานของ HTML และประมวลผลโดย PHP ใน `admin.php` เมื่อมีการส่งข้อมูลแบบ POST.

## 🛢️ โครงสร้างฐานข้อมูล (Database Schema)

ฐานข้อมูล `price_calculator` ประกอบด้วย 4 ตารางหลัก:

* **`materials`**: เก็บข้อมูลวัสดุต่างๆ ที่ใช้ในการผลิต.
    * `material_id`: ID ของวัสดุ.
    * `product_type`: ประเภทของสินค้าที่ใช้วัสดุนี้ (เช่น 'ตัวอักษรโลหะ', 'ผ้าไวนิล').
    * `material_name`: ชื่อของวัสดุ (เช่น 'สแตนเลส', 'พลาสวูด 10 มม.').
    * `price_per_unit`: ราคาต่อหน่วย.
    * `unit`: หน่วยของราคา (เช่น 'บาท/นิ้ว', 'บาท/ตรม.').
    * `display_in_calculator`: สถานะการแสดงผลในหน้าคำนวณ (1 = แสดง, 0 = ซ่อน).
* **`options`**: เก็บข้อมูลออปชันเสริมต่างๆ.
    * `option_id`: ID ของออปชัน.
    * `option_name`: ชื่อออปชัน (เช่น 'ค่าแรงติดตั้ง', 'เย็บขอบ').
    * `option_price`: ราคาของออปชัน.
    * `category`: หมวดหมู่ของออปชัน (เช่น 'ทั่วไป', 'สติ๊กเกอร์') เพื่อให้แสดงผลในเครื่องคำนวณที่ถูกต้อง.
    * `display_in_calculator`: สถานะการแสดงผล.
* **`price_rules`**: เก็บกฎและค่าคงที่ที่ใช้ในการคำนวณ.
    * `rule_id`: ID ของกฎ.
    * `rule_name`: ชื่อกฎ (เช่น 'ติดตั้งนอกเมือง', 'ติดตั้งในเมือง').
    * `rule_value`: ค่าของกฎ.
    * `rule_unit`: หน่วยของค่า (เช่น 'บาท/กม.', 'บาท').
    * `display_in_calculator`: สถานะการแสดงผล.
* **`stock`**: เก็บข้อมูลสินค้าคงคลัง.
    * `stock_id`: ID ของสต็อก.
    * `product_name`: ชื่อสินค้าในสต็อก.
    * `product_type`: ประเภทของสินค้า.
    * `quantity`: จำนวนคงเหลือ.
    * `unit`: หน่วยนับ.
